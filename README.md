# web-dev-playground

![React](https://img.shields.io/badge/-React-blue?logo=react&logoColor=white)

## 📝 Description

Dive into the world of full-stack web development with web-dev-playground! This project is a curated collection of mini-projects designed for hands-on learning. Built with React on the frontend and featuring backend functionalities like API integration, database management (MongoDB), user authentication, robust testing, and even a command-line interface (CLI), it provides a comprehensive learning experience. Perfect for developers of all levels looking to solidify their skills and explore new technologies in a practical, building-focused environment.

## ✨ Features

- 🌐 Api
- 🗄️ Database
- 🔐 Auth
- 🧪 Testing
- 💻 Cli

- **build**: `npm run build`
- **lint**: `npm run lint`

- **THIS_MAKEFILE_PATH**: `make THIS_MAKEFILE_PATH`
